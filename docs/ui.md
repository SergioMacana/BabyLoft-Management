# Diseño de interfaz de usuario

La aplicación tendrá la siguientes pantallas

1. Pantalla 1: Pantalla principal del administrador que muestra un resumen del estado de los pedidos mediante tarjetas (Nuevos, En producción, Listos y Enviados). Incluye una sección inferior con los pedidos más recientes y una barra de navegación con un botón central destacado para crear nuevos registros.
   
<img width="362" height="581" alt="image" src="https://github.com/user-attachments/assets/2951a41c-852f-4167-9aaa-aa1391270b78" />

2. pantalla 2: Listado completo de todos los pedidos registrados. Cuenta con un sistema de filtros por estado en la parte superior y presenta cada pedido en tarjetas que resumen el cliente, el precio total, los materiales elegidos (tela, color) y su estado actual.

<img width="408" height="581" alt="image" src="https://github.com/user-attachments/assets/7fa24032-3dca-47db-9343-2a2db67ec4cb" />

3. pantalla 3: Vista a profundidad de una orden específica. Muestra el estado actual con un botón para actualizarlo, una línea de tiempo visual del progreso del pedido, y tarjetas separadas con la información de contacto del cliente, las características del producto y los detalles de personalización.

<img width="361" height="577" alt="image" src="https://github.com/user-attachments/assets/8700b463-51c4-4f92-a34b-a7d4c9208111" />

4. pantalla 4:(cliente) Primera vista del flujo de creación de pedidos. Contiene un formulario básico para capturar los datos de contacto del comprador: nombre completo, usuario de Instagram y número de teléfono o WhatsApp.

<img width="350" height="577" alt="image" src="https://github.com/user-attachments/assets/c7e09c19-efee-4bf9-985e-2e84a309ca69" />

5. pantalla 5: (cliente) Segunda vista del flujo de creación, enfocada en los materiales. Permite seleccionar el tipo de producto y tela mediante menús desplegables, elegir el color a través de una paleta visual e indicar la talla del artículo.

<img width="344" height="576" alt="image" src="https://github.com/user-attachments/assets/7ba1b9a5-ff46-43d6-9732-08711b2fc33b" />

6. pantalla 6: (cliente) Último paso del registro. Incluye campos para ingresar el texto a bordar, selección de la fuente tipográfica, un área para notas especiales y un campo numérico para ingresar el valor total del pedido en COP y el resumen del pedido y la confirmacion de este.

<img width="333" height="569" alt="image" src="https://github.com/user-attachments/assets/0f0a847d-d0c9-4fb9-a07c-82d35e1e269a" />

7. pantalla 7: Pantalla de retroalimentación visual que se muestra al finalizar la creación de una orden. Presenta un mensaje principal de éxito ("¡Pedido creado!") junto con un ícono destacado, confirmando el nombre del cliente registrado y el estado inicial asignado. Incluye un botón de acción central ("Ver todos los pedidos") para redirigir al usuario de vuelta al listado general.

<img width="356" height="575" alt="image" src="https://github.com/user-attachments/assets/5a54e4f2-f112-47c2-872c-8a2105cfe054" />
