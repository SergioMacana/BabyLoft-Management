# Funcionalidades

La siguientes es una lista de las funcionalidades disponibles para el usuario de la aplicación:

* **1.** Crear y editar pedidos.
* **2.** Registrar información del cliente.
* **3.** Registrar telas y colores.
* **4.** Registrar personalizaciones.
* **5.** Adjuntar imágenes de referencia.
* **6.** Gestionar estados.
* **7.** Consultar pedidos pendientes.
* **8.** Filtrar por estado o fecha.
* **9.** Ver materiales necesarios.
* **10.** Notificaciones de cambios importantes.
* **11.** Historial de pedidos.
